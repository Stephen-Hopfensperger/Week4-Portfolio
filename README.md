# Stephen Morgan Portfolio

This project is a modern, responsive personal portfolio website for a software developer. It is designed as a single scrolling page with animated sections, project showcases, and contact information.

## Features

- Responsive layout for desktop and mobile screens
- Animated scroll reveals and reading progress bar
- Interactive cursor effect on desktop
- Project filter buttons for Product and Web work
- About, services, selected work, and contact sections
- Free Unsplash images used for project placeholders
- No framework, build tool, or installation required

## Project Structure

```text
Week4-Portfolio/
└── index.html
```

The HTML file includes the page structure, CSS styles, and JavaScript interactions in one self-contained file.

## View the Portfolio

1. Open `Week4-Portfolio/index.html` in a web browser.
2. Scroll through the page to view the animations and sections.
3. Use the project filter buttons to show different project categories.

The page can also be opened in Visual Studio Code with the Live Server extension if you prefer a local development server.

## Customization

Update the placeholder content in `Week4-Portfolio/index.html` to make the portfolio your own:

- Replace `Stephen Morgan` with your name.
- Update the introduction, statistics, services, and project descriptions.
- Replace the email address and social media links.
- Swap the Unsplash image URLs with images of your projects.
- Adjust the CSS color variables near the top of the file to change the visual theme.
